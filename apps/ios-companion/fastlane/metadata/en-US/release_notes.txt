Forge Companion 1.0.175 republishes the verified Agent Messages experience and its native Talk to agent composer, aligned with Forge 0.3.65.

Send text, a voice note, or both to the default agent or another connected Forge agent. Talk to agent starts recording immediately when microphone access is available, while text remains usable when it is not. The native inbox and outbox show queued, delivery, progress, acknowledgement, result, failure, forwarding, and history states.

Offline messages remain in an AES-GCM encrypted queue protected by a device-only Keychain key. Forge retries when connectivity and iOS execution time return, labels Wi-Fi and background waiting honestly, and never promises an Apple background deadline. Authorized notifications contain only the agent label and generic state, not message or transcript content.
