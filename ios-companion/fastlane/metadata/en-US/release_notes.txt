Forge Companion 1.0.117 makes HealthKit sync diagnostics more precise while keeping the faster Iroh bridge path from 1.0.116.

The sync panel now separates phone-side transport wait, Iroh bridge timing, and Forge backend processing time, so long waits no longer appear as vague "ACK" or generic Forge blocking.

When a pairing uses Iroh with a Tailscale HTTPS fallback, the app now says that explicitly instead of calling the active upload path an "Iroh tunnel."
