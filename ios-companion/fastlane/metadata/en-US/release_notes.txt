Forge Companion 1.0.60 hardens interrupted HealthKit sync and historical workout upload.

The app now preserves accepted chunk progress across retries, freezes retry windows
only when Forge resumes the same upload session, and starts a fresh window when
Forge replaces an expired session.

Large movement, workout metric, and route uploads continue in byte-stable chunks so
Forge can skip previously accepted chunks instead of re-uploading the whole import.

The runtime contract now reports mobile sync progress with fields that match the
actual server payload, keeping generated clients and diagnostics aligned.

This TestFlight build uploads without automatic external group distribution. CI
continues to skip beta review submission while keeping build processing and
changelog verification.
