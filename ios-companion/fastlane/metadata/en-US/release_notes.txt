Forge Companion 1.0.40 fixes HealthKit chunk verification for large workout histories.

Workout chunks now send byte-stable payloads, so Forge verifies exactly the JSON bytes
the phone hashed instead of reserializing nested HealthKit evidence and occasionally
rejecting it as a checksum mismatch.

If a previous upload session hit the checksum bug, retry now starts a clean resumable
sync instead of looping on the rejected chunk.
