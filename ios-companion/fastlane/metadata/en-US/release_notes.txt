Forge Companion 1.0.61 fixes repeated historical workout uploads after backgrounding.

Health sync checkpoints now remember completed workout batches, so resuming the
same Forge upload session skips workouts that were already fully accepted instead
of rebuilding their heart-rate samples and routes from HealthKit again.

Large HealthKit chunks now use iOS background URLSession file uploads on HTTP
pairings, which is Apple’s supported path for uploads that need to survive app
suspension.

HTTP workout and route chunks are smaller to avoid proxy 502 failures while still
letting Forge skip accepted chunks by stable chunk id.

This TestFlight build keeps beta review submission disabled while CI uploads the
IPA, waits for processing, and attaches this changelog.
