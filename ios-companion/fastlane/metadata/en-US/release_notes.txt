Forge Companion 1.0.122 makes HealthKit sync progress clearer when HealthKit chunks are already sent but still waiting for a network reply.

The sync panel now uses the actual per-chunk route label. Bulk uploads over a Tailscale URL are shown as Tailscale direct, and Iroh is shown only when the request really uses Iroh or falls back to it.

The wording no longer says Forge is the blocker for every outstanding request. It separates phone queueing, network replies, Forge acceptance rate, and Forge server processing time. HealthKit cursors, upload checkpoints, pairing state, and upload behavior are unchanged.
