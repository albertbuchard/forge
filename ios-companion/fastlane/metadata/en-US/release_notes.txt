Forge Companion 1.0.125 fixes transport selection for Tailscale pairings and improves Watch sync behavior.

When the companion is paired through a secure Tailscale URL, HealthKit sync now stays on Tailscale direct transport instead of mixing in Iroh metadata or downgrading bulk uploads to insecure HTTP. Iroh is only used for actual forge-iroh pairings.

The sync card now prefers the active transfer state over stale "synced" text, so long-running uploads show what is being prepared or uploaded instead of sitting on an old workout count.

The Watch app now receives scoped companion connection metadata and tries direct HTTPS/Tailscale API calls for refreshes and command batches. It keeps the iPhone relay as a fallback when watchOS cannot reach Forge directly.

HealthKit cursors, upload checkpoints, pairing state, and stored user data are unchanged.
