Forge Companion 1.0.129 tightens Tailscale and Iroh route handling in the iOS and watch companions.

Tailscale pairings now stay labeled and prioritized as Tailscale even if old Iroh metadata is still present in stored pairing data. Discovery now prefers Tailscale before Iroh when both are advertised.

Sync status now reports phone-side bytes as sent, Forge-side bytes as accepted, and names Tailscale network replies instead of generic Forge replies. Completed sync messages no longer show trigger labels such as manual as if they were transports.

Regression coverage was added for stale Iroh metadata on Tailscale URLs, Tailscale-first discovery ranking, and the updated sync progress wording.

HealthKit cursors, upload checkpoints, pairing state, and stored user data are unchanged.
