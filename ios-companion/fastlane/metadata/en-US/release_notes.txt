Forge Companion 1.0.89 fixes pairing and reconnect routing for Iroh-first companion sync.

New Iroh pairings no longer expose localhost as a phone-facing API or UI URL. The app now uses the Iroh tunnel by default and only keeps Tailscale, LAN, or fixed-IP fallbacks when Forge actually provides a phone-reachable address.

Re-pairing now switches the active Forge cleanly, cancels stale sync work from the previous pairing, and remembers prior Iroh/direct endpoints separately so they can be selected again without trying to sync against an old server.
