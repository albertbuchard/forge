Forge Companion 1.0.137 makes reachable watch actions sync through the iPhone relay faster.

When the watch cannot reach Forge directly but the iPhone is reachable, action acknowledgements now return in the same WatchConnectivity request instead of waiting for a separate acknowledgement message.

If the iPhone cannot submit the action to Forge, the watch keeps the action marked as still to send and the phone stores it for later retry. The UI no longer calls that state queued.

The Tailscale/Iroh separation remains in place: secure Tailscale URLs stay on the Tailscale path, and Iroh is only used for active forge-iroh pairings.

HealthKit cursors, upload checkpoints, pairing tokens, watch action queues, and stored user data are unchanged.
