Forge Companion 1.0.49 changes HealthKit workout history sync to use a
compressed workout archive path when the paired Forge runtime supports it.

Workout batches are sent as deflated archive chunks that contain the full
workout objects, including samples and routes. Forge stores those chunks and
then imports them on the server side, instead of making the phone split each
batch into separate summary, time-series, and route uploads.

The sync panel keeps the active transfer state visible during a sync and avoids
replacing it with stale Health permission text while upload work is still
running.

Older Forge runtimes remain supported through the previous chunk families until
the server plugin has been updated.
