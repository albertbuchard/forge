Forge Companion 1.0.44 makes HealthKit sync easier to verify while it is running.

The Settings sync card now shows the current upload stage, counted payload records,
active chunk family, bytes, and sync session while a manual sync is in progress.

There is now a collapsible Sync logs panel above the Run sync button, with a copy
action for diagnostics when a sync appears stuck.

Workout uploads keep the raw workout-history backfill path and now report chunk-level
errors with the family, chunk id, and byte count so retries and support logs identify
where the upload stopped.
