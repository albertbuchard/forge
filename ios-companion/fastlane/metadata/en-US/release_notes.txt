Forge Companion 1.0.132 fixes the remaining mixed Tailscale/Iroh sync status label.

If the active pairing route is Tailscale, sync status now reports Tailscale. If the active route is Iroh, it reports Iroh, even when stale pairing metadata still contains an older Tailscale URL.

This keeps the UI aligned with the actual upload route and removes another source of confusing hybrid transport wording during HealthKit uploads.

The update also keeps the existing stale "Synced ..." message suppression during active transfers, so the panel should continue showing the current upload stage instead of an old completed stage.

HealthKit cursors, upload checkpoints, pairing state, and stored user data are unchanged.
