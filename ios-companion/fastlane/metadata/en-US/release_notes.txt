Forge Companion 1.0.131 separates Tailscale and Iroh routing for companion sync.

When a pairing includes a secure Tailscale URL, the companion now normalizes the active route to Tailscale before chunk uploads and watch bootstrap sharing. Iroh stays active only for Iroh-only pairings.

This removes the hybrid path where an Iroh pairing could silently send HealthKit chunks through a Tailscale fallback and show confusing mixed transport labels.

The watch app also receives its direct API connection from the normalized active pairing URL, so stale Iroh metadata cannot override an active Tailscale route.

HealthKit cursors, upload checkpoints, pairing state, and stored user data are unchanged.
