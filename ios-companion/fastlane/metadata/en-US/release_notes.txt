Forge Companion 1.0.144 makes watch direct sync retry Tailscale much sooner after transient watch-network failures.

The watch still uses direct HTTPS/Tailscale whenever the secure companion URL is reachable. Iroh remains limited to active forge-iroh pairings.

Direct watch requests now time out after 3 seconds instead of 6 seconds before falling back to the phone, so a bad watch network path blocks the user for less time.

After a recoverable direct-route failure, the watch retries direct Forge access after 3 seconds instead of waiting 20 seconds, so it returns to Tailscale faster when the route comes back.

Watch fallback code and tests now use phone fallback wording instead of relay wording. User-visible sync copy continues to avoid queued action, Iroh tunnel, and iPhone relay wording for Tailscale sessions.

HealthKit cursors, upload checkpoints, pairing tokens, watch action persistence, and stored user data are unchanged.
