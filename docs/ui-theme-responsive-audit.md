# Forge UI Theme And Responsive Audit

This document tracks the active view-by-view audit for theme responsiveness and screen-size responsiveness. It is not a substitute for fixing code; it is the checklist that prevents losing scope while the fixes proceed.

Audit rules:

- Every routed view must be checked at desktop and mobile widths.
- Every page-owned component and imported UI component listed below must either respond to theme tokens or be explicitly justified as intentionally fixed-tone media/canvas chrome.
- Hardcoded dark-only utility colors such as `text-white`, `bg-white/*`, `border-white/*`, raw black panels, and raw rgba focus/border styles are audit targets unless already covered by a compatibility bridge.
- Fixed-width tables, minimum-width rows, non-wrapping action bars, absolute overlays, graph controls, and modal footers are responsive audit targets.
- A row is only `checked` when the live route has been inspected and no ugly horizontal overflow or theme-incoherent component remains for that route.
